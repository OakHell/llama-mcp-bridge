# llama-mcp-bridge

## Overview

`llama-mcp-bridge` is a local Model Context Protocol (MCP) bridge connecting clients to a local `llama-server` instance.

- **Output Hygiene:** Strips internal reasoning/monologue tags while preserving fenced code blocks, LaTeX, and structured content.
- **Gitignore-Aware Discovery:** Discovers files and directories while respecting `.gitignore` cascades, `!` negations, `include > ignore` precedence, and context budgets.
- **Cross-Platform Hardware Profiling:** Detects NVIDIA, AMD ROCm, Apple Silicon, Intel, and CPU fallbacks across Linux, macOS, Windows, and FreeBSD, generating tuned `models.ini` presets.

## Quickstart

1. **Synchronise Dependencies:**
   ```bash
   uv sync
   ```

2. **Install & Validate (Dry Run):**
   ```bash
   uv run llama-mcp-install --dry-run
   ```

3. **Run the Bridge:**
   ```bash
   uv run llama-mcp-bridge
   ```

## Configuration

- `LLAMA_MCP_HOME`: Root configuration directory (defaults to `~/.config/llama-mcp-bridge`, with `/mnt/ai` fallback compatibility).
- `bridge.ini`: Controls `host`, `port`, `auto_spawn`, `health_timeout_s`, and `request_timeout_s` (see `bridge.example.ini`).
- `models.ini`: Generated by `llama-mcp-install` for your detected VRAM tier (`6gb`, `8gb`, `12gb`, `16gb`, `24gb+`).
